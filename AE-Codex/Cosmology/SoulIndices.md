# Soul Indices

> The four ways a soul behaves under pressure. Each Soul Index = a "race / ancestry slot" with a fixed cosmic temperament. Mapped onto the four operative deadly sins of Lucifer's spark cosmology: **Wrath, Pride, Greed, Envy**. Players choose one at character creation. Soul Index is **separate from Body Tag and from Class** — the cosmic-flavor axis of the 2-axis character creation.

---

## What a Soul Index is — LOCKED

*[T1: Source doc §1.1, marked LOCKED]*

- **Soul Index = your race/ancestry slot** in this cosmology
- It defines **how your soul behaves under pressure** — your default "problem-solving mode"
- **Separate from Body Tag** (HUM / CYB / SYN — the physical-form axis; see [`../Mechanics/BodyTags.md`](../Mechanics/BodyTags.md))
- **Separate from Class** (the skill / vocation layer)

Character creation is therefore **2-axis-plus-class**:

| Axis | Choices | Determines |
|---|---|---|
| **Soul Index** | Boiler / Crown / Maw / Mirror | Cosmic temperament; spark-flavor |
| **Body Tag** | HUM / CYB / SYN | Physical form; task gating |
| **Class** *(D&D-specific)* | TBD | Vocation / mechanical role |

Plus customizations and player-narrated backstory.

## The four Soul Indices — LOCKED

*[T1: Source doc §2 axis table + §3-6 details, all marked LOCKED]*

### Cosmological mapping

The four Indices map onto **four of the seven deadly sins** — the ones that drive the spark's behavior most prominently:

| Index | Sin | Subtitle | Cosmic flavor |
|---|---|---|---|
| **Boiler-Type** | **Wrath** | Redline | Frame-bound, world-first, immediate. Burns hot. Refuses to back down. |
| **Crown-Type** | **Pride** | Command | Systematic, world-first, rhythmic. Routes power through chains-of-command. |
| **Maw-Type** | **Greed** | Hoarder | Systematic, balanced, eventual. Always slightly better at fiddling with things for value. |
| **Mirror-Type** | **Envy** | Adaptation | Wild, self-first, rhythmic. Reads danger patterns; takes the form of what hurt them. |

> [!important] **Cosmological resonance**
>
> The four Indices are the operative manifestations of **the spark Lucifer planted in humanity** (per [`Substrate.md → "The Spark"`](Substrate.md#the-spark--divine-source-of-life)). The "rebellion / being-better-than-what-came-before" impulse takes one of four shapes per soul: **anger that breaks limits (Boiler) / hierarchy that imposes structure (Crown) / acquisition that gathers power (Maw) / mimicry that adapts to threat (Mirror)**.
>
> The other three deadly sins (Lust, Gluttony, Sloth) are **not Indices** — possibly because they're insufficiently active to drive transcendence, or because they fall under the surface-pleasure category Lucifer didn't optimize for. *(Open question — never explicitly addressed in source.)*

### Behavioural axes — LOCKED

Each Index has a fixed **1–3 profile on three axes**:
- **Structure:** 1 Wild / 2 Framed / 3 Systematic
- **Plasticity:** 1 World-first / 2 Balanced / 3 Self-first
- **Tempo:** 1 Eventual / 2 Rhythmic / 3 Immediate

**Design constraint (LOCKED):** each Index has exactly **one 1, one 2, one 3** across the three axes.

| Soul Index | Structure | Plasticity | Tempo |
|---|---:|---:|---:|
| **Boiler** | 2 Framed | 1 World-first | 3 Immediate |
| **Crown** | 3 Systematic | 1 World-first | 2 Rhythmic |
| **Maw** | 3 Systematic | 2 Balanced | 1 Eventual |
| **Mirror** | 1 Wild | 3 Self-first | 2 Rhythmic |

## Soul Index kit structure — LOCKED

*[T1: Source doc §1.3, LOCKED]*

Every Soul Index gives a player:

| Component | What |
|---|---|
| **Skill Imprint** | +1 Offset to **two skills**, each with tight, on-theme triggers (skill-only — never modifies attacks/damage/DCs directly) |
| **Active** | One signature "button" (per rest / per scene / per encounter) |
| **Passive** *(optional — some have none)* | Long-cycle or always-on effect |
| **Drawback** | Always-on penalty |

**Stacking rule (LOCKED):** if multiple instances of the **same named Soul Index feature** could apply to the same roll/effect (e.g. two Crowns' Grids on one attack), **only one instance applies** — the creature making the roll chooses which.

## Per-Index mechanical specifics

> [!note] **Format note**
> The full mechanical kit is **locked in the source doc** (Skill Imprints, Actives, Passives, Drawbacks per Index). For VN format these may be simplified or substituted with narrative analogues. **Listed here as headlines; full mechanics in source.**

### Boiler-Type (Wrath / Redline)
- **Skill Imprint — Furnace Presence:** +1 OFS to **Pry** (raw force / leverage) and **Soul Grit** (refuse to drop)
- **Active — Overboil:** 1×/Long Rest. High-risk damage overdrive — Pressure scales 0→3 as you keep dealing damage; bonus die scales (d4/d6/d8) BOTH ways (you deal more, you take more)
- **Passive — Tomorrow's Wounds:** 1×/Long Rest. Defer one Minor/Major Injury to your next Trueflow Long Rest
- **Drawback — Blunt Logic:** −1 OFS on all **Riddlecraft** checks
- **Sub-feature:** Boiler Super-Shove during Overboil (push 10ft + prone + Pressure-die bludgeoning)

### Crown-Type (Pride / Command)
- **Skill Imprint — Executive Protocol:** +1 OFS to **Influence** (rank/contract/regulation) and **Guile** (structured deception / cover ID)
- **Active — Priority Target / Grid:** 1×/major conflict scene. Mark up to 2 allies as Under Command + 1 hostile as Priority Target; for next 2 turns, attacks vs target get +1d4
- **Passive — None** (Crown has no passive)
- **Drawback — Can't Carry Alone:** in multi-step teamwork challenges, attempting to solo multiple steps → −d4 OFS on later solo checks

### Maw-Type (Greed / Hoarder)
- **Skill Imprint — Tinker's Greed:** +1 OFS to **Tinker** (open/disarm/repurpose for loot) and **Riddlecraft** (puzzles gating loot)
- **Passive — Hidden Pocket:** one personal-scale item carries as 0 BL
- **Active — Deep Cut / Jackpot Pull:** 1×/Trueflow Long Rest. On a loot-gate check, GM rates Tier 1-3, roll Tier d4, choose one result, add as OFS
- **Drawback — Loot Itch:** 1×/scene, first failed loot-gate check inflicts 1d4 psychic damage (cannot drop below 1 HP)

### Mirror-Type (Envy / Adaptation)
- **Skill Imprint — Echo Sense:** +1 OFS to **Stillsense** (reading threats) and **Godsight** (reading wards/sanctity/spoor)
- **Passive — Adaptive Shell:** can be adapted to one damage type at a time. First hit of a new type imprints (no reduction). After: 1×/round, reduce damage of the adapted type by 1d6 (min 0). Change/clear once per Short/Long Rest.
- **Active — Reflected Strike:** 1×/scene. When you hit a target while you have a Current Adaptation, treat the hit's damage as the adapted type and add +1d4 damage
- **Drawback — Raw Pattern:** non-combat check with no Advantage / no Help / no positive random bonus → −d4 OFS

## Backgrounds — LOCKED template

*[T1: Source doc §7]*

Soul-Index-flavoured backgrounds are **narrative-first**. Each grants **exactly one** small mechanical micro-boost:

- **Type A — Skill Focus (static):** pick one skill + narrow trigger; +1 OFS when triggered
- **Type B — Scene Push (spike):** pick one skill + narrow trigger; 1×/scene, +1d4 OFS when triggered

Backgrounds may have narrative permissions, contacts, story hooks — but mechanically only the single micro-boost above. *Skill-check only — no attack rolls, no damage, no HP, no movement, no inventory/currency.*

## VN format — what carries over, what defers

**Carries over for VN format (cosmological / narrative):**
- All 4 Index identities + cosmological sin-mapping
- The temperament descriptions (Wild/Framed/Systematic, World/Balanced/Self, Eventual/Rhythmic/Immediate)
- The flavor of each Index's signature behavior
- Index choice as character-creation step

**Defers for VN format (D&D-specific mechanics):**
- Specific dice formulas (Pressure d4/d6/d8, Adaptive 1d6, etc.)
- Skill OFS modifiers (no Offsets system in VN)
- Long Rest / Short Rest / Scene cooldown bookkeeping
- Stacking-rules-with-multiple-of-same-Index (in VN single-character, irrelevant)

For VN, each Index becomes a **character-archetype tag** that:
- Colors the tone of the protagonist's reactions
- Unlocks specific dialogue choices ("a Boiler-Type might say...")
- Gates a small number of narrative options
- Translates the mechanical kit into 2-3 narrative-relevant traits per Index
